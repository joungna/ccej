# 경실련 보도자료 지식맵 (CCEJ Press Knowledge Map)

경실련(경제정의실천시민연합, ccej.or.kr)이 공개한 보도자료 405건을 인터랙티브 지식맵(knowledge map) 형태로 탐색할 수 있는 정적 웹사이트입니다. 순수 HTML/CSS/JavaScript로 제작되었으며, 별도 빌드 과정 없이 정적 파일만으로 GitHub Pages 등 어떤 정적 호스팅에도 바로 배포할 수 있습니다.

**본 사이트는 경실련(ccej.or.kr) 공개 보도자료를 기반으로 제작된 비공식 아카이브입니다.** 경실련과 공식적인 제휴·협력 관계는 없으며, 보도자료 원문·이미지·첨부파일은 모두 ccej.or.kr에 게시된 원본 URL을 그대로 참조합니다(로컬에 미러링하지 않음).

## 주요 기능

- **지식맵 시각화**: D3.js force simulation 기반으로 405개 보도자료를 노드로 표현. 노드 색상은 카테고리(정치/경제/부동산/사회/도시/통일/사법/소비자/국제/기타), 크기는 본문 길이, 아이콘은 게시물 유형(첨부파일/이미지/동영상/행사/공지/보고서/텍스트)을 나타냅니다.
- **월별 클러스터링**: 초기 상태에서는 게시물이 작성 월(月) 기준 앵커 좌표 주변에 뭉쳐 보이며, 확대(zoom in)할수록 클러스터링 힘이 약해지면서 개별 노드로 자연스럽게 퍼집니다.
- **팬/줌/드래그**: 마우스 휠 줌, 드래그 팬, 더블클릭 확대, 노드 드래그 재배치를 지원합니다.
- **검색 & 필터**: 제목/본문/태그/작성자/카테고리 실시간 검색, 연도·월·태그(다중선택)·유형·키워드·첨부파일/이미지/동영상 유무 필터를 AND 조건으로 동시 적용합니다.
- **월별 내비게이션 칩**: 월별 게시물 수를 보여주는 칩을 클릭하면 해당 월 클러스터로 확대·필터링됩니다.
- **상세 패널**: 노드를 클릭하면 우측(모바일은 전체화면) 패널에 제목·날짜·작성자·카테고리·3줄 요약·본문 전체·첨부 이미지·첨부파일 다운로드 링크·태그·원문보기 링크·관련 게시물 5건이 표시됩니다.
- **리스트 뷰**: 하단 드로어에서 필터링된 게시물을 리스트로 확인하고, 스크롤 시 20~30개씩 점진적으로 렌더링(무한 스크롤)됩니다.
- **성능 최적화**: 초기 로드는 가벼운 `search-index.json`으로 처리하고, 상세 정보(첨부파일/이미지/동영상/조회수 등)가 필요한 `posts.json`은 백그라운드에서 비동기 로드 후 메모리에 캐시하여 지도를 점진적으로 보강합니다. 이미지 썸네일은 `loading="lazy"`로 지연 로드됩니다.
- **반응형**: PC/태블릿/모바일, 세로/가로 레이아웃을 모두 지원하며 모바일에서는 필터·리스트가 바텀시트, 상세 패널이 전체화면 오버레이로 전환됩니다.

## 기술 스택

- Tailwind CSS (CDN, Play CDN 빌드) — 화이트 기반 미니멀 디자인
- D3.js v7 (CDN) — force simulation, zoom/pan, drag
- Lucide Icons (CDN)
- 순수 Vanilla JavaScript (빌드 도구 없음)

## 폴더 구조

```
ccej-press-map/
├── index.html              # 메인 SPA 페이지
├── assets/
│   ├── app.js               # 지식맵 로직 (D3 시뮬레이션, 필터, 검색, 상세 패널 등)
│   └── style.css            # 커스텀 스타일
├── data/
│   ├── posts.json           # 게시물 405건 전체 데이터 (본문/첨부/관련글 등)
│   ├── search-index.json    # 경량 검색 인덱스 (초기 로드용)
│   ├── tags.json            # 태그별 게시물 수/ID 목록
│   └── months.json          # 월별 게시물 수
└── README.md
```

## 로컬 실행

빌드 과정이 필요 없습니다. 저장소를 내려받은 뒤 아무 정적 파일 서버로 루트에서 서빙하면 됩니다.

```bash
cd ccej-press-map
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 데이터 출처

본 사이트에 수록된 보도자료 메타데이터(제목/날짜/본문/첨부파일/이미지 등)는 경실련 공식 웹사이트(https://ccej.or.kr)에 게시된 공개 보도자료를 크롤링하여 정리한 것입니다. 원본 이미지·첨부파일(PDF/HWP 등)은 로컬로 복제하지 않고 ccej.or.kr에 게시된 원본 URL을 그대로 참조합니다. 각 게시물의 "원문보기" 버튼을 통해 언제든 경실련 공식 페이지에서 원문을 확인할 수 있습니다.
